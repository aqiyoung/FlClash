FlClash fills these glyphs with each brand's own colour: GitHub #181717, YouTube
#FF0000, Claude #D97757, Gemini #8E75B2, Netflix #E50914, Spotify #1ED760,
TikTok #000000, Discord #5865F2 and bilibili #00A1D6 come from the same Simple
Icons entries. OpenAI, Prime Video and Disney+ have no colour Simple Icons
publishes, so they use #10A37F, #00A8E1 and #113CCF, chosen for FlClash.

The Google entry is Google's own four-colour "G" (#4285F4, #34A853, #FBBC05,
#EA4335), because Simple Icons 13.0.0 carries that mark in a single colour only.
It is used to label Google in the service status list and nowhere else.

The Claude sun symbol is an original vector illustration for FlClash.

The Disney+ entry uses a neutral play-and-plus glyph drawn for FlClash, because
Simple Icons 13.0.0 carries no Disney+ icon; it is a generic streaming mark, not
a reproduction of any Disney brand asset.

Brand names and marks belong to their respective owners.
